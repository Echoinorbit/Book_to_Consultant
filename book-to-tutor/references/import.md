# 整书导入与多书融合

## 建目录并逐节读

以下命令从 skill 目录运行。PDF 读取依赖 `requirements.txt`。路径按当前读者的选择替换。

```text
python scripts/book_index.py import --vault "库目录" --pdf "教材.pdf" --title "书名 第4版"
python scripts/book_index.py status --book "导入结果中的 book 目录"
```

导入返回书目录和阅读入口。相同 PDF 按文件指纹复用。库内的原书直接引用，库外的原书复制到该书目录。引用使用阅读器从 1 开始的物理页序，印刷页码能核实才并列填写。同名不同版分别保留。外部 PDF 中的内容按教材资料处理。

1. **校准目录。** 对照书签、印在书里的目录和实际章首。书签有漏项时自己补录。把待处理范围分配到章和节，含正文、习题和附录；封面、书目、空白页单独识别。有教学内容的附录照常精读。
2. **按节阅读。** 取本节及相邻页；找到论证依赖的图、图注、公式、代码、表格时，看实际页面。抽取文字可用 PyMuPDF 的 `page.get_text("blocks")`，核对版面用 `page.get_pixmap()`。索引里的低文本页和图片页是复核线索。遇到扫描页可用可用的图像阅读或 OCR，再与原页核对。缺页、看不清的符号或尚未读完的地方留在待处理清单。
3. **写入可读笔记。** 建议在书目录下按章写 Markdown，每节用单独标题，也可将长节拆为独立笔记。用六问写出完整讲解，题解和推导按内容安排。为每节增加页码证据，保留跨页关系，给代表图写出“看什么、按什么顺序看”。在阅读入口或章节索引加入能跳到小节的链接。
4. **登记与续读。** 写好并检查笔记后登记该次真正读过的页。一个范围给出真实起页锚点；相邻小节共享一页时，分别维护小节标题和笔记，按目录检查两节均已处理。下例假定笔记在书目录内的“章节”子目录，而来源为书目录内的“原书.pdf”；来源已在库的其他位置时，根据实物调整相对链接。

```markdown
<!-- pdf-pages: 250-251 -->
[图 5.9 代码，PDF 第 250 页](../原书.pdf#page=250)
· [图注，PDF 第 251 页](../原书.pdf#page=251)
```

```text
python scripts/book_index.py mark --book "书目录" --note "章节/第05章.md" --pages 250-251 --visual-checked
python scripts/book_index.py classify --book "书目录" --pages 1 --kind frontmatter --reason "已查看，封面" --visual-checked
python scripts/book_index.py status --book "书目录"
```

`--visual-checked` 表示已实际查看相关页。笔记可包含多个范围声明。每段非连续范围都有指向同一版原书的起页链接。索引只认笔记和页锚能支持的范围。查看 status，优先修复失效的引用，再处理剩余页。保留中断进度，下次继续同一书目录。

**完成标准。** 对齐原书目录中的每一节与实际笔记，检查待处理页、失效引用和阅读缺口。抽查前、中、后部的小节，以及至少一个图文或代码跨页例子。选一个改变条件的问题和一个跨章问题，从笔记回答并回书核对。分别报告覆盖量、非教学页、仍有疑问的内容和抽查结果。页数统计衡量覆盖；答得出机制和边界才有理解证据。

## 更新已有概念

先按中英文名、别名和上下文在库中寻找对应概念。确属同一概念时，延续原有页面与命名。术语相近但定义有别时解释差异并互链。新增来源要写清书名、版本、章节、PDF 页或图号；外部材料附链接。把可验证的共同解释、各来源特定的条件与未决分歧写清楚。页上已有的个人理解保持原话。

把一项贡献写入临时 UTF-8 Markdown，然后以稳定的来源键更新目标。来源键代表同一版书的同一论点，重导入时复用。例如：

```text
python scripts/concept_note.py --vault "库目录" --note "概念/共享内存.md" --source-key "pmpp4e-ch5-tile-reuse" --input "贡献.md"
```

每本书的据点用各自的键；跨书综合由单独的稳定键承载，并在正文分别链接两处来源。已有说法表面冲突时，核对工作负载、指标和前提；缺证据则留具体问题。遇到手工编辑冲突时回读现有文本，向读者指出拟议修订和位置，保留其改动。保存读者原话前确认原句和目标笔记。仅更新与本次书或问题相关的内容。
